# diskhog

Консольное приложение для поиска «пожирателей» места на диске: сканирует диск
или каталог, строит интерактивное дерево каталогов и файлов с размерами и
позволяет удалять ненужное прямо из интерфейса (в корзину или навсегда,
с подтверждением).

## Зависимости

Нужен [uv](https://docs.astral.sh/uv/). Установка зависимостей:

```
uv sync
```

## Запуск

```
uv run diskhog                # текущий каталог
uv run diskhog D:\            # весь диск D:
uv run diskhog D:\projects    # конкретный каталог
```

## Клавиши

| Клавиша | Действие                                          |
|---------|---------------------------------------------------|
| ↑ / ↓   | перемещение по дереву                             |
| → / Enter | раскрыть каталог (← — свернуть)                 |
| f       | топ-100 самых больших файлов (Enter — показать в дереве) |
| d       | удалить выбранное в корзину (с подтверждением)    |
| D       | удалить навсегда (с подтверждением)               |
| h       | скрыть/показать файлы (оставить только каталоги)  |
| o       | открыть расположение в Проводнике                 |
| r       | пересканировать                                   |
| s       | остановить сканирование                           |
| q       | выход                                             |

В строке каждого элемента: имя, полоска-индикатор, размер на диске и доля от
корня сканирования. В панели снизу — подробности о выбранном элементе
(логический размер, число файлов, дата изменения, ошибки доступа).

## Как считаются размеры

* **on disk** — сколько байт реально занято на томе: для сжатых/разреженных
  файлов берётся фактическая аллокация (Windows API `GetCompressedFileSizeW`),
  для остальных — размер, округлённый вверх до кластера тома; на POSIX —
  `st_blocks * 512`.
* **logical** — логический размер файла (`st_size`).

Симлинки и junction не обходятся и не учитываются (содержимое считается по
настоящему расположению). Если под одним узлом больше 500 детей, показываются
первые 500 по размеру, остальные — строкой «… N more» (клавиша `h` скрывает
файлы целиком).
